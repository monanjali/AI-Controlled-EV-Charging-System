## AI-Controlled-EV-Charging-Station
AI-controlled multi-source EV charging station with intelligent power management using ESP32, Node.js, IoT, renewable energy integration, and a real-time dashboard built using HTML, CSS, and Javascript. 

## Project Objective
- To develop an intelligent EV charging Station capable of monitoring solar and DC charging sources in real time using ESP32, Node.js, and IoT Technologies.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- ESP32
- IoT
- Renewable Energy Monitoring

## Features
- Real-time dashboard monitoring
- Solar and DC voltage tracking
- ESP32-based voltage transmission
- Backend API using Node.js
- Smart charging management
